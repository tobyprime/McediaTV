# McediaTV — 游戏内多媒体播放系统

> 适用版本:**McediaTV 1.3.0** / **McediaCore 1.2.4** / **Mcedia China Platforms 1.2.4** / **Mcedia TV Plugin 1.2.2**
> 支持的 Minecraft 版本:**1.21.11 / 26.1（含 26.1.1、26.1.2）/ 26.2**

## 这是什么？

McediaTV 是一套在 Minecraft 里看视频、放电影、同步观看的媒体系统。它让玩家能在游戏世界中创建**屏幕播放器**，把 Bilibili 视频、番剧、直播间、抖音视频等内容在屏幕上一块块地播放出来，并且**多个玩家可以围在同一个屏幕前同步观看、共同控制**。

**它是为 Paper / Folia 服务器设计的，必须配合服务端插件 Mcedia TV Plugin 才能使用**（单人世界、无插件的原版服务器以及纯模组服均无法使用）。

它主要由以下几个部分组成：

- **McediaTV（客户端 Mod）**：屏幕播放器的展示、同步观看与控制界面
- **McediaCore（客户端 Mod）**：负责视频解码、音频、弹幕、画面渲染的底层播放引擎
- **Mcedia China Platforms（客户端 Mod）**：负责把 Bilibili、抖音等平台的链接解析成可播放的媒体
- **Mcedia TV Plugin（服务端插件）**：维护频道状态、同步数据与播放器管理，是整套系统能运转的核心

---

## 核心特色

### 屏幕播放器
- 在服务器中创建 MTV 播放器，绑定频道后即可播放内容
- 一个频道可同时被多个玩家观看，所有观众围绕同一条播放时间线同步播放
- 多个播放器也可以共用一个频道，展示完全相同的内容

### 世界内屏幕控制
- 准星对准屏幕即可浮现控制界面，无需打开任何菜单
- 播放 / 暂停、上一个 / 下一个、倍速、音量、亮度、弹幕开关
- 直接在屏幕上浏览播放列表：翻页、跳转、上移 / 下移 / 置顶 / 置底、删除
- 打开添加媒体界面时，需**准星瞄准播放器屏幕的右下角**并单击加号

### 添加媒体与专辑导入
- 点击「添加媒体」，粘贴链接即可预览并加入播放列表
- 支持插到开头、插入下一首、追加、立即播放
- 粘贴 Bilibili 番剧季度、单集或收藏夹链接，可**一键「加入专辑」**，把整季一次性加进列表

### 播放控制权限
- 私有播放器可开启「允许他人控制播放」，让任意玩家遥控
- 服务端也可通过权限节点精确控制谁能操作

## 快速开始

### 客户端

- **Windows x86-64（绝大多数玩家）**：安装对应 MC 版本的 **McediaTV allinone（一体化）** 一个 Mod 文件即可，已内置 Windows native 库。
- **Linux / macOS 等非 Windows 平台**：仍然只安装同一个 **McediaTV allinone** Mod；首次启动时在游戏内下载对应平台的 **native 库 ZIP**，不需要安装其他 Mod。下载完成后 native 会保存到 `config/mcedia/native/` 并动态加载。

> 注意：Mod 版本必须与你的 Minecraft 版本一致（当前支持 1.21.11 / 26.1 / 26.2）。

### 服务端

- 需为 **Paper / Folia 服务器**，安装 **Mcedia TV Plugin**，插件启动后自动生成配置文件。
- McediaTV 非为模组服设计；单人世界、无插件的原版服务器以及纯模组服（如 Forge / 其他环境）无法使用。

### 使用流程

`/mtv` 打开管理界面 → 创建播放器并绑定频道 → 准星瞄准屏幕右下角单击加号，粘贴视频 / 番剧 / 直播链接 → 屏幕开始播放，周围玩家同步观看与控制。

## 客户端使用指南

### 观看与屏幕控制
- **观看**：准星对准 MTV 屏幕即可观看。
- **控制**：准星对准屏幕时浮现控制界面，可执行播放 / 暂停、切上下集、倍速、音量、亮度、弹幕开关等操作。
- **播放列表**：展开控制界面可在屏幕播放列表中翻页、跳转、移动、删除。

### 添加媒体与专辑导入
**准星瞄准播放器屏幕的右下角，单击加号**即可打开添加媒体界面：

- 粘贴**单个链接**，选择插入位置（开头 / 下一首 / 追加 / 立即播放）。
- 粘贴 **Bilibili 番剧（`ss`）、单集（`ep`）、收藏夹（`ml`）链接**，会出现「加入专辑」按钮，一键加入整季。

### MTV HUD 小窗（实验性，可选）
提供屏幕外的小窗预览命令（**该功能仍在实验阶段**，可能不稳定或随版本调整）：

```
/mcedia mtv hud status            查看当前 HUD 订阅的频道与屏幕状态
/mcedia mtv hud screen on|off     开启 / 关闭 HUD 屏幕
/mcedia mtv hud pos <x> <y>       设置 HUD 屏幕位置
/mcedia mtv hud size <w> <h>      设置 HUD 屏幕尺寸
```

### Bilibili 账号登录（可选）
部分 Bilibili 内容需要登录态才能播放，可扫码登录一次：

```
/mcedia platforms bilibili login      生成二维码，用 Bilibili 手机 App 扫码登录
/mcedia platforms bilibili account    查看当前登录状态
/mcedia platforms bilibili logout     清除本地登录信息
```

> 登录信息只保存在你的客户端本地，不会上传到服务器。

### 播放设置
分辨率上限、活跃解码器数量、弹幕开关等播放相关设置可在客户端配置文件中调整；音量、弹幕等也可以在播放过程中通过屏幕控制界面即时调节。

## 服务端配置指南（面向管理员）

### 配置文件

插件启动后生成 `plugins/McediaMtvPlugin/config.yml`：

```yaml
world-ui:
  rate-limits:
    control-per-second: 10    # 单个玩家每秒可发送的控制操作数
    page-per-second: 4        # 播放列表翻页请求限流（每秒）
    watch-per-second: 2       # 屏幕观看状态请求限流（每秒）
```

- **control-per-second**：播放 / 暂停 / 切歌 / 添加媒体等控制操作的限流。普通服务器保持默认即可；高延迟或多人同时操作时可适当调高。
- **page-per-second**：播放列表翻页与数据请求限流。
- **watch-per-second**：对准屏幕的观看状态订阅限流。

### 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `mtv.player.create` | true | 创建 MTV 播放器 |
| `mtv.player.edit` | true | 编辑自己的播放器（屏幕 / 扬声器 / 播放 / 移动 / 删除） |
| `mtv.player.edit.others` | op | 编辑 / 删除别人创建的私有播放器 |
| `mtv.player.control.others` | op | 控制 / 切换别人私有播放器的播放与频道 |
| `mtv.player.teleport` | op | 传送到 MTV 播放器 |
| `mtv.gui` | true | 打开 MTV 管理界面 |
| `mtv.channel.create` | true | 创建公共频道 |
| `mtv.channel.manage.others` | op | 管理别人创建的公共频道 |
| `mtv.channel.control.others` | op | 控制别人创建且未开放控制的公共频道 |
| `mtv.hud.subscribe` / `mtv.hud.unsubscribe` | true | HUD 订阅 / 取消订阅频道 |
| `mtv.admin` | op | 以上所有权限的汇总 |

### 播放控制权限说明
- **公开 / 无主播放器**：任何玩家均可控制。
- **私有播放器**：控制权依次为 拥有者 → 拥有 `mtv.player.control.others` 权限的玩家 → 开启「允许他人控制播放」后任意玩家。
- 管理员可在播放器管理界面中切换「允许他人控制播放」。

### 管理命令
```
/mtv    打开 MTV 管理界面
```
创建播放器、创建 / 搜索频道、绑定、公开 / 私有、控制权限等操作均通过管理界面完成。

## 常见问题（FAQ）

**Q: 我该下载哪个文件？**
Windows x86-64 客户端下载 McediaTV 对应 MC 版本的 **allinone** Mod 一个文件即可。Linux/macOS 客户端也下载同一个 Mod；首次启动时下载的是对应平台的 native 库 ZIP，不是另一个 Mod。

**Q: 必须在装有插件的服务器里才能用吗？**
是的。McediaTV 依赖服务端插件 Mcedia TV Plugin 维护频道状态与同步数据，**没有插件的服务器 / 单人世界无法使用**。

**Q: 这是给模组服用的吗？**
不是。McediaTV 是给 **Paper / Folia 服务器**设计的。

**Q: 这会占用服务器带宽转发媒体内容吗？**
不会。服务端插件只维护频道状态、处理订阅与同步数据，不中转完整媒体流。实际网络行为取决于媒体来源与解析 Mod 的实现。

**Q: 能直接播放 Bilibili、抖音的链接吗？**
可以。安装 Mcedia China Platforms 后，支持 Bilibili 视频 / 番剧 / 直播与抖音视频链接。

**Q: 可以导入整个专辑或收藏夹吗？**
可以。粘贴 Bilibili 番剧季度、单集或收藏夹链接后，点击「加入专辑」即可一键加入整季。

**Q: 一个频道可以同时被多个玩家观看吗？**
可以。频道是播放状态的中心，多个玩家订阅同一频道后围绕同一状态同步播放。

**Q: 其他玩家无法控制我的播放器？**
你的播放器是私有的。可在服务端管理界面开启「允许他人控制播放」，或由管理员授予对方 `mtv.player.control.others` 权限。

**Q: 有些 Bilibili 内容播放不了？**
可能是需要登录态的内容，请先用 `/mcedia platforms bilibili login` 扫码登录。此外实际可播放性还取决于平台返回的媒体地址与平台接口变化。
