01 · Overview

综合简述

McediaTV（简称 MTV）是 Mcedia 生态下的多媒体播放系统。它允许玩家在 Minecraft 世界中创建实体电视播放器，播放网络媒体内容，并通过弹幕、多屏多扬声器等特性提供沉浸式观影体验。

适用环境：Paper 1.21+ / Folia，需安装 Mcedia Core 与 McediaTV 客户端模组。服务端为 Bukkit 插件，客户端为 Fabric / NeoForge 模组。

系统架构

MTV 采用 C/S 分离架构：服务端插件管理播放器实体、频道状态与权限；客户端模组负责媒体解码、画面渲染与音频输出。两端通过自定义网络数据包同步状态。

模块 位置 职责
MTV Plugin 服务端 播放器创建/持久化、频道管理、观众心跳、权限校验、GUI
MTV Client 客户端 媒体解码播放、画面渲染（ItemDisplay 实体映射）、音频路由
Mcedia Core 两端 媒体解析器、解码器配置、Screen/Speaker 外设抽象

核心概念

MTV 播放器

Minecraft 世界中的 ItemDisplay 实体。每个播放器可挂载多块屏幕和多个扬声器，绑定一个频道，以此决定播放内容。

频道（Channel）

播放状态与媒体列表的容器。分为两种类型：

  • SELF 频道（私有）— 每个播放器创建时自动生成，仅归属者可操作。
  • BROADCAST 频道（公共）— 可被发现与订阅，支持完整播放列表与多种播放模式。

观众（Audience）

靠近播放器范围的玩家自动成为观众，通过心跳包（每 5 秒）保活。服务端 30 秒 无心跳视为超时。观众状态影响播放器是否保持激活。

外设（Peripheral）

  • 屏幕 — 渲染视频画面，可配置尺寸、位置、旋转、填充模式、亮度与弹幕显示。
  • 扬声器 — 输出音频，可配置音量、范围与声道模式（mix / left / right）。
02 · Player Guide

玩家使用指南

本章面向服内玩家，涵盖从创建播放器到日常使用的完整操作流程。所有管理操作均可通过 GUI 完成。

创建 MTV 播放器

手持物品，站在目标位置，输入：

/mtv create <名称>

系统将在你当前位置创建一个 ItemDisplay 实体播放器，并自动进入播放器管理界面。创建者默认被标记为所有者。权限：mtv.player.create（默认所有玩家拥有）。

主菜单

输入 /mtv 或 /mtv gui 打开主菜单。包含以下入口：

  • 附近的播放器 — 列出周围 50 格内的 MTV 播放器，快速进入管理。
  • 公共频道 — 浏览和搜索可发现的公共频道，订阅后自动播放。
  • 创建公共频道 — 将自己的播放器频道设为公开。

播放器管理

从附近的播放器列表选择一个播放器，进入管理界面：

播放控制

  • 输入媒体链接 — 点击"设置播放"，在聊天框粘贴支持的媒体 URL，按回车确认。
  • 暂停/继续 — 一键切换播放状态。
  • 播放列表管理 — 添加、移除、排序媒体项。支持列表播放、列表循环、单曲循环、随机播放、播完即停五种模式。
  • 速度调节 — 调整播放倍速。
  • 跳转 — 快进/快退（相对跳转），或指定起始时间。

屏幕设置

  • 尺寸 — 设置屏幕宽度与高度。
  • 位置偏移 — 微调屏幕相对播放器的位置。
  • 旋转 — 设置屏幕朝向（四元数）。
  • 填充模式 — keep_aspect_cover（等比填充）/ keep_aspect_fit（等比适配）/ stretch（拉伸）。
  • 亮度 — 最低 8，最高 15（默认 8）。
  • 弹幕开关 — 是否在屏幕上显示弹幕。
  • 背景纹理 — 空闲时显示的背景图片。

扬声器设置

  • 音量 — 0–1.0 浮点数。
  • 听觉范围 — 声音能传播的最远距离（格）。
  • 声道模式 — mix（混合立体声）/ left（左声道）/ right（右声道）。
  • 位置偏移 — 微调扬声器相对播放器的位置。

其他操作

  • 总音量 — 播放器全局音量，0–1.0。
  • 电源开关 — 关闭后画面停止、声音静音，但配置保留。
  • 移动到此处 — 将播放器传送到玩家位置。
  • 删除 — 移除播放器（含所有外设）。

遥控器快捷操作

手持名为"遥控器"的铁门物品（IRON_DOOR），右键空气或方块，即可打开遥控菜单，无需输入命令。

公共频道

创建公共频道后，其他玩家可搜索发现并订阅。公共频道支持：

  • 完整的播放列表管理（添加、删除、排序）。
  • 五种播放顺序模式任意切换。
  • 公开控制：开启后任何玩家均可控制播放（暂停/切歌等）；关闭后仅创建者可操作。
03 · Admin Guide

服务器管理员指南

本章面向服务器管理员，涵盖安装配置、权限管理、数据持久化与性能优化建议。

安装要求

组件 要求
服务端 Paper 1.21+ 或 Folia（已标记 folia-supported: true）
客户端 Fabric / NeoForge，安装 Mcedia Core + McediaTV Client 模组
依赖 Mcedia Core（提供媒体解码与渲染能力）
插件需安装于 plugins/ 目录。频道数据持久化于 plugins/mtv/channels/ 目录（JSON 格式）。

权限体系

完整权限列表如下。建议使用权限管理插件（如 LuckPerms）进行分配。

权限节点 默认 说明
mtv.admin op 父权限，包含以下所有子权限
mtv.player.create true 创建 MTV 播放器
mtv.player.edit true 编辑播放器（屏幕/扬声器/播放/移动/删除）
mtv.player.edit.others op 编辑他人创建的私有播放器
mtv.player.teleport op 传送到 MTV 播放器
mtv.gui true 打开 MTV 管理 GUI
mtv.channel.create true 创建公共频道
mtv.channel.manage.others op 管理他人创建的公共频道
mtv.channel.control.others op 控制他人频道（非公开控制时）

数据存储

播放器配置存储在 ItemDisplay 实体的 NBT 数据中，随区块保存。频道播放状态存储在文件系统：

plugins/mtv/channels/
  ├── channel_<id1>.json
  └── channel_<id2>.json

服务启动时自动从文件系统加载频道状态，每次状态变更后自动落盘。移除频道时同步清理对应文件。

系统参数

参数 默认值 说明
观众超时 30000ms 客户端无心跳超过此时间，视为观众离线
频道同步间隔 100 ticks（5s） 周期向所有观众广播频道状态快照
观众清理间隔 20 ticks（1s） 定期清理过期观众会话

性能考量

  • 每个 MTV 播放器对应一个 ItemDisplay 实体，实体量大的服务器注意实体数量上限。
  • 频道状态变更会向所有已订阅客户端的广播快照。公共频道观众过多时，网络带宽是主要瓶颈。
  • 插件已原生支持 Folia 线程调度，所有实体操作均使用 Player#getScheduler 而非 Bukkit 同步任务。
  • 频道数据采用文件系统存储而非数据库，适合中小规模部署。大批量频道场景建议评估 I/O 压力。
04 · Developer Guide

开发人员指南

本章面向希望对 MTV 进行二次开发或集成其他系统的开发者，介绍模块结构、关键 API 与扩展点。

项目结构

mcedia-mtv-plugin/          # 服务端 Bukkit/Paper 插件
  src/main/java/.../
    channel/                 # 频道核心逻辑
    command/                 # /mtv 命令
    controller/              # 外设与播放控制入口
    gui/                     # 库存 GUI 页面系统
    listener/                # 事件监听
    manager/                 # 播放器管理
    model/                   # 领域模型
    selector/                # 播放器选择逻辑
    util/                    # 工具类

mcedia-mtv/                  # 客户端 Fabric/NeoForge 模组
  src/client/java/.../
    channel/                 # 客户端频道会话与同步
    entityplayer/            # ItemDisplay 实体渲染映射
    mixin/                   # 渲染 Mixin

服务端 API 概览

MtvPlayerManager

播放器管理的核心入口。提供异步操作接口：

  • readSnapshot(UUID, Consumer<ManagedMtvPlayer>) — 读取播放器配置快照
  • withManagedPlayer(UUID, Function, Consumer) — 安全地获取并操作播放器
  • createPlayerAsync(Location, String, Player, Consumer) — 异步创建播放器
  • setScreenSize / setSpeakerVolume / ... — 外设配置修改（异步持久化）

MtvChannelService

频道状态的管理与播放控制：

  • resolveBinding(ManagedMtvPlayer) — 解析播放器的频道绑定（SELF 或 BROADCAST）
  • togglePause(String channelId) — 切换暂停
  • updateMediaUrl / updateSpeed / updateStartAt — 更新播放参数
  • appendPlaylistItem / insertNextPlaylistItem / removePlaylistItem — 播放列表操作
  • cyclePlayOrderMode — 切换播放顺序模式
  • ensureChannelState(String channelId) — 获取或创建频道运行时状态

AudienceSessionManager

观众与会话生命周期管理：

  • subscribe / unsubscribe — 订阅/退订频道
  • touch(UUID, String, ...) — 心跳上报，返回状态变更与时长变更标记
  • pruneExpired(long nowMs) — 清理过期会话
  • summarize(String channelId) — 汇总观众状态（时长、完成度、加载状态、挂起数量）

网络协议

服务端与客户端通过 Minecraft 自定义负载数据包通信。所有数据包使用 FriendlyByteBuf 序列化。

通道标识 方向 用途
mcedia_mtv:channel_subscribe C → S 客户端请求订阅频道
mcedia_mtv:channel_unsubscribe C → S 客户端退订频道
mcedia_mtv:channel_snapshot S → C 频道状态快照（媒体 URL、时间轴、播放状态）
mcedia_mtv:channel_sync S → C 周期同步更新
mcedia_mtv:channel_remove S → C 频道被移除通知
mcedia_mtv:channel_heartbeat C → S 观众心跳（含加载状态、播放进度、解码器状态）

时间轴模型

MTV 采用服务端权威时间模型，关键属性：

  • mediaTimeMs — 媒体层已处理的时间偏移（设置后不随播放递增）
  • playTimeMs — 播放器进入 PLAYING 状态的系统时间戳
  • computeCurrentMediaTimeMs(nowMs) = mediaTimeMs + (playing ? nowMs - playTimeMs : 0)

客户端根据快照中的锚点时间 anchorMediaTimeUs、已消逝时间 elapsedTimeMs 和本地单调时钟，计算目标播放位置并同步。

播放顺序模式

模式 行为
SEQUENTIAL 顺序播放到列表末尾后暂停
SHUFFLE 随机选取下一首
LOOP_ALL 从头到尾循环
LOOP_ONE 单曲循环
CURRENT_ONLY 播完当前即停

GUI 扩展

GUI 系统使用页面注册模式。新增页面需：

  1. 在 MtvGui.GuiType 枚举中添加新类型。
  2. 实现 GuiPage 接口（type()、open()、renderFromEntry()、handleClick()）。
  3. 在 MtvGui 构造器中通过 registerPage() 注册。

播放器选择策略

当玩家附近有多个播放器时，MtvPlayerSelector 根据距离、激活范围及电源状态提供智能选择推荐。可扩展 SelectorStrategy 自定义选择逻辑。

扩展建议
如需集成其他插件（如 PlaceholderAPI、自定义计分板等），建议通过 MtvChannelService 获取频道状态，避免直接操作 ItemDisplay 实体的 NBT。
Appendix

附录

A. 术语表

MTV：Mcedia Television，本系统的简称。

频道（Channel）：封装媒体播放状态的逻辑容器。SELF 为私有，BROADCAST 为公共。

外设（Peripheral）：屏幕（Screen）或扬声器（Speaker）的统称。

弹幕（Danmaku）：屏幕上飘过的用户评论。

观众（Audience）：正在观看/收听某个频道的玩家。

ItemDisplay：Minecraft 中用于展示物品的实体类型，MTV 播放器的载体。

遥控器：名为"遥控器"的 IRON_DOOR 物品，右键打开远程菜单。

Folia：Paper 团队开发的区域化线程调度服务端实现。

B. 相关项目

  • Mcedia Core — 媒体解析、解码与播放核心库
  • McediaTV Plugin — 本系统的服务端插件
  • McediaTV Client — 本系统的客户端模组
