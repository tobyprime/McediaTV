# MTV 世界播放器手工验收

## 客户端与插件组合

- [ ] 新客户端 + 新插件：收到能力协商后才显示右下角按钮，并能展开控制条。
- [ ] 新客户端 + 旧插件：不显示世界控制，不影响旧 HUD 和频道播放。
- [ ] 旧客户端 + 新插件：频道容器 GUI 和旧播放流程保持可用。
- [ ] 1.21.11、26.1、26.2 分别启动并验证入口、Mixin 和渲染事件加载成功。

## 世界屏幕交互

- [ ] 准星移到实际 MTV 屏幕右下角才显示小展开按钮，移开后隐藏。
- [ ] 左键展开，再次点击同一按钮收起；没有命中热区时左键仍交给 Minecraft。
- [ ] 屏幕被方块遮挡时客户端不发送控制请求，伪造 UV/UUID 在服务器被拒绝。
- [ ] 不设置交互距离限制；跨世界、未知屏幕和错误频道绑定仍被服务器拒绝。
- [ ] 拖动进度和音量期间无持续网络包，松开各发送一次最终值。
- [ ] 控制条只出现在命中的 MTV 屏幕，并被实体/方块的正常深度遮挡。

## 播放列表与预览

- [ ] 超过 32 项的列表按页加载，单页编码不超过 24 KiB，滚动可继续请求缺页。
- [ ] 粘贴 URL 后由客户端解析并显示标题、作者、描述、平台和 Cover；解析失败时按钮保持禁用。
- [ ] 加入请求被拒绝时全屏界面保留 URL 与预览；收到同一 requestId 的接受结果后关闭。
- [ ] Cover 下载失败显示 fallback，不向服务器提交元数据或封面。

## 兼容与负载

- [ ] 控制请求超过 10/s、分页超过 4/s、watch 超过 2/s 时只返回限流结果。
- [ ] 播放、暂停、上一首/下一首、音量、加入播放列表和播放顺序操作与容器 GUI 状态一致。
- [ ] MTV 外设位置、尺寸、旋转、亮度和扬声器配置仍只能从 Bukkit 容器 GUI 修改。
- [ ] 玩家退出、换世界、MTV 删除和插件关闭后 watch 状态清理，不产生心跳式 UI 状态包。
